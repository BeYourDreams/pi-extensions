## 8. 体检与排障

### 8.1 体检脚本（都在仓库根，手跑）

| 脚本 | 干什么 | 期望 |
|---|---|---|
| `node check-readme-tables.mjs` | readme 表格列数（编辑时插/漏 `\|` 靠它兜住） | 一致 exit 0 |
| `node install-local-extensions.mjs --check` | 本地扩展副本与仓库是否逐字节一致；孤儿报 `[orphan]` | 一致 exit 0 |
| `node install-project-config.mjs --check` | `config/` 与 pi 实际读取位置是否一致（CRLF/LF 归一后再比） | 一致 exit 0 |
| `node fix-lazy-tools-notes.mjs --check` | lazy-tools 的 DOCS_NOTE 路径补丁是否被 `pi update` 冲掉 | 基线已修好 exit 0 |
| `node fix-proper-lockfile-proxy.mjs --check` | proper-lockfile 补丁在位（防 jiti Proxy 崩 pi） | 一致 exit 0 |
| `node fix-pi-one-ui-theme.mjs --check` | pi-one-ui 内置主题里是否还有 schema 不认的 `colors` 键；npm 与 git 两份副本一起扫 | 合规 → `[skip]` / exit 0；`[待修补]` exit 1 时不带 `--check` 重跑即修 |
| `node sync-drama-skills.mjs check` | 旧 drama 线镜像是否漂移（`CUSTOM` 已清空，现在恒无漂移，仅为历史保留） | 无漂移 exit 0 |

> `.sc-test/` 目录（`check-ext-errors.mjs` 等一次性探针）属 gitignore、**不入库**，升级/清理会丢，别当长期工具。

**改完必做**：`/reload` → 看 TUI 有无 `extension_error` → `pi --no-session -p "reply with: ok"` 冒烟 → 跑上表前三个 `--check`。

### 8.2 排障表

| 症状 | 原因 | 处置 |
|---|---|---|
| 扩展报 `Tool "x" conflicts with ...` | 两个扩展抢同一工具名 | 二选一卸载（CHANGELOG [§7.1](../CHANGELOG.md)） |
| 懒加载报 `Cannot find module` | lazy 执行层地基缺失（版本要与 pi 本体一致，别写死） | `npm i --prefix ~/.pi/agent @earendil-works/{pi-coding-agent,pi-tui,pi-ai}@$(pi --version \| grep -oE '[0-9]+\.[0-9]+\.[0-9]+')` |
| 工具调用不到、wire 上也没有 | 内建工具不在 `defaultTools`（不注册），扩展工具不在其中（被 lazy） | 改 `defaultTools`（[§3.1](配置.md)），`/reload` |
| `fd` / `rg` 报找不到 | `pi-reflag` 改写后依赖这两个二进制 | `npm i -g fd-find ripgrep`，或确认 pi 自带的 `~/.pi/agent/bin/` 在 PATH |
| 会话/文件撤销 | `pi-edit-guard` / `pi-checkpoint` 均已卸载 | 文件级靠 git 或改前先 `read`；会话级 `/undo` 不再可用 |
| agent 没有 shell | `defaultTools` 里没有 `bash` | 写 `bash` 进两处 `defaultTools`（[§3.1](配置.md) / [§3.2](配置.md)） |
| 宠物没起来 / 凭空消失，`log.txt` 里每行都是 `窗客户端 0` | 窗进程活着但渲染进程崩了 = 僵窗 | 上游已修（CHANGELOG [§7.25](../CHANGELOG.md)）；临时 `/pet-auto restart`；扩展那层 60s 后自己换（[§3.3](配置.md)） |
| `/pet` 提示命令不存在 | 只 `npm i -g` 装过，pi 不扫全局 `node_modules` | `pi install git:github.com/BeYourDreams/pi-dsh-pet` → `/reload`（[§3.3](配置.md)） |
| 宠物窗口不弹 | 首次要下 Electron ≈100MB；或自动启动被关了 | 看启动提示；`/pet-auto status` 看开关；关掉了就写回 `{"autostart": true}` |
| `pi list` 里某行带 `(filtered)` | 该包在 `packages` 里写成 object form 且注明了要屏蔽的部分 | **预期**（本机只有 `pi-dsh-pet (filtered)`，[§3.3](配置.md)） |
| 压缩后首轮命中低 / `cacheRead: 0` | 内置压缩的前缀与活会话不续写，必然 0 | **正常现象**（CHANGELOG [§7.13](../CHANGELOG.md)） |
| 切了 caveman / ponytail 档位后本轮 `cacheRead: 0` | 换了 system 前缀文本，首轮必然重算 | **正常**，别反复切；第二轮起恢复（[§3.5](配置.md)） |
| 输出突然变碎句 / 掉冠词 | caveman 档位生效（ASD-STE100 两层，含 L1 选词断句） | `/optimizer` 开面板调档（**无 `/optimizer <mode>` 文本参数形**）；值在 `pix.json`（[§3.5](配置.md)） |
| 输出突然变「懒」/ 开始砍功能（YAGNI 口吻） | ponytail 档位生效（本机默认 `ultra`） | `/optimizer` 调档；只影响「写什么」，验证/错误处理/安全不裁 |
| bash 命令前莫名多出 `rtk ` 前缀 | RTK 执行层在改写命令 | **预期行为**；`/optimizer` 里关掉即停；二进制缺失时不改写（[§3.5](配置.md)） |
| 每条 bash 输出前带 `[rtk] /!\ No hook installed` | rtk 找的是 Claude 风格 hook，pi 走 pix 的 `tool_call` 改写 | `%APPDATA%\rtk\config.toml` 的 `[hooks] suppress_hook_warning = true`（先 `rtk config --create`，CHANGELOG [§7.24](../CHANGELOG.md)） |
| 第一次开 pi 时 footer 出现下载 `rtk` 二进制 | RTK 开着且 PATH / `binary.json` 都找不到 `rtk` | **预期**，下到 `~/.pi/agent/bin` 并校验 checksum；离线设 `PI_OFFLINE` 跳过 |
| **浅色终端里 footer 的 cwd 发白** | `cwd` 是 pi-one-ui 唯一默认用裸 ANSI 色的字段，退到 `bold cyan` | `pi-one-ui.json` 写 `{"colors":{"cwd":"accent"}}` 后 `/reload`（[§3.8](配置.md)）。**别改主题、别钉 hex** |
| 开机 / `/reload` 弹 `[Theme conflicts] Invalid theme …` | pi ≥1.0 主题 schema 收严，旧 pi-one-ui 内置主题非法 | `node fix-pi-one-ui-theme.mjs` 后 `/reload`（§8.1） |
| pi 整个进程崩，只留 `TypeError: Proxy handler's 'get' result …`（frame 指向 `proper-lockfile/lib/mtime-precision.js`） | jiti interop 把 mtime 缓存包成 Proxy，第二次加锁触发 JSC 不变量 | `node fix-proper-lockfile-proxy.mjs`（幂等）；升 pi 本体后复发就重跑（CHANGELOG [§7.14](../CHANGELOG.md)） |
| `pi --no-session -p ...` 不退出（shell 报 exit 124） | 桌宠的 `/feed` 长连接或宿主进程挂着父会话 | 用 `timeout 70 pi ...` 包一层（[§3.3](配置.md) 已屏蔽上游扩展，刷屏的重连日志也没了） |
| 装/卸包时 npm 打 `EBADENGINE` | 某包声明的 engine 高于本机 node 24.16.0 | **可忽略**（引警告）；本机当前 9 个包都不触发 |
| GitHub 不通 / TLS 握手失败 | 国内出口或自定义根 CA 劫持 | 走 `gh-proxy.com` 镜像（[§2.1](../readme.md)）；rtk 二进制用 `curl --ssl-no-revoke`（[§3.5](配置.md)） |

### 8.3 磁盘布局速查

| 路径 | 内容 |
|---|---|
| `~/.pi/agent/settings.json` | `packages` 注册表 + `defaultTools`（含 dsh-pet 的 object form 屏蔽，[§3.3](配置.md)）+ [§3.4](配置.md) 的备忘项 |
| `~/.pi/agent/extensions/` | 本地扩展副本 + 各扩展的全局配置（`pi-dsh-pet.json` 等；**只放这里，放 agent 根下不生效**） |
| `~/.pi/agent/state/` | 跨会话记账，现只剩 `pi-pet-autostart.json` + `spawn-log.txt` |
| `~/.pi/agent/git/` | git 源扩展：`pi-lazy-tools` / `pi-dsh-pet`（扩展被屏蔽）/ `pi-one-ui` |
| `~/.pi/agent/npm/node_modules/` | npm 源扩展 |
| `~/.pi/agent/npm/package.json` | **6 个 dep**（无 `allowScripts` 键，CHANGELOG [§10](../CHANGELOG.md) · 原 3.1） |
| `~/.pi/agent/pix.json` | `@xynogen/pix-optimizer` 三档状态（[§3.5](配置.md)） |
| `~/.pi/agent/pi-one-ui.json` | pi-one-ui 覆盖项（`colors.cwd`，[§3.8](配置.md)） |
| `~/.pi/agent/bin/` | RTK 官方二进制（[§3.5](配置.md)）+ pi 自带 `fd` |
| `%APPDATA%\rtk\config.toml` | **rtk 二进制自己的配置**（与 pi 无关），见排障表 |
| `~/.pi/agent/config/` | **空**（新装带 `startupConfig` 的包才会写） |
| `~/.pi/agent/mcp-onboarding.json` | 内建 MCP 引导向导状态，**勿手改** |
| `<仓库>/config/pi-project/settings.json` | **留档件**（2026-11-13 起不拷入 `.pi/`：项目级 `defaultTools` 整体覆盖用户级会顶掉全局配置） |
| `<仓库>/config/agent/AGENTS.md` | 用户级规则 canonical 源（**0B**，[§5](使用纪律.md) 定案不发规则） |
| `~/.pi/agent/sessions/**/*.jsonl` | 会话历史 |

**生效方式**：改配置或扩展后 `/reload`（不重启会话、不丢历史）。
