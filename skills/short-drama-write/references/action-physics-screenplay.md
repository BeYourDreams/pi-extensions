# 动作物理与可生成性（剧本层）

`SCR-23 · reviewed_invariant`。把「动作写成模型和演员都能正确执行的物理步骤」，而不是把细节
交还给模型猜。本文管剧本层的动作写法；分镜阶段另有朝向重述与拆镜衔接，视频阶段另有起始帧核对，
三层共用同一套词汇：因果链、领先接触、中段进入、未完成原因→对应结果。

## 1. 为什么剧本层就要管物理

AI 执行端按默认值填空：位移动词不绑朝向，模型延续首帧身体方向直接平移或倒退——「背对门进入」
就是这么来的；不写先迈哪只脚，下一镜换手换脚接不住；不写门开向，人物能穿门而过。分镜和视频
阶段只能逐层补救已经写歪的因果，救不回剧本本身没想清楚的动作。剧本层的动作物理是整条管线
最便宜的一次修正。

## 2. 因果链六项

位移或界面动作落笔前，先在上下文解一遍，不落盘：

```text
主体 → 起点位置与身体朝向 → 路径与移动方向 → 领先接触（哪只手/哪只脚）
→ 目标对象与物理连接 → 可见结果（含终点位置与朝向）
```

只回答影响执行的问题。简单位移（走两步拿起杯子）不用写满六项，朝向会被误读才写：
镜头外没人知道她朝哪走，就写；从上下文必然推出，就不写。

判断方法：这段动作交给一个看不见画面的人照着演，他若必须自己发明朝向、手脚或开关方式才能
走完，就是没写全；他若照着演会撞墙，就是写错了物理。

## 3. 动作容量换算

执行窗按单镜 ≤12 秒、10 秒左右最佳设计（分镜阶段 SHT-31 定最终镜长）。剧本不写镜长，但要为「一段连续动作能装多少」负责：

| 计一步 | 例子 |
| --- | --- |
| 朝向反转（转身） | 从面朝窗转到面朝门 |
| 一次位移动（≤3 步） | 桌到门 |
| 一次跨界 | 门槛、车门、楼梯口 |
| 一次界面开合 | 门、帘、盖、抽屉 |
| 一次单手取放 | 拿钥匙、放杯子 |

**一拍 = 一条链 ≤ 两步。** 超载链的三个合法出路：

- **拆拍分场**：写成两个动作段，中间用可见结果衔接（「门推开一条缝」/「她人已站在门外」）；
- **中段进入**：本段直接从链的中间写起——「她右手已搭在内门把上，向左拉门」，
  进入前的部分留给上一段或直接省略；
- **明确省略**：`[转场]` 声明跳过，不留「随后她进了房间」这种无机构过渡。

对白挤占同一拍时，先估台词发声秒数（见 SKILL 时长估算），剩下的窗口再数动作步数；
「说完长台词 + 转身 + 走到门 + 推门 + 跨槛」两头都超载。

## 4. 高风险动作改写

模型高失败率动作可以出现在戏里，但不能**承重剧情信息**。改写表：

| 原写法（高风险） | 改写（高频动作 + 可见结果） |
| --- | --- |
| 他两根手指夹起米粒大小的芯片 | 他把芯片按进卡槽，指尖压了两次才对齐 |
| 她眼中闪过一丝不易察觉的怀疑 | 她视线移开半拍，把登记表翻回刚才那页 |
| 他接住从桌上扫落的钢笔 | 钢笔掉在地上，他俯身捡起，顿了一下才递过去 |
| 她一边倒车一边解开安全带并回头看 | 车停稳后她摘下安全带回头（拆拍，或动作放台词后） |
| 他以厘米级幅度把证据推离镜头 | 他合上文件夹，双臂压住（结果承担信息） |

两条纪律：

- 精确性本身是戏（拆弹、开锁、手术）时，让**失败风险可见**——手抖、滑脱、掉落在地——
  不要求执行端一次演准，把紧张交给结果和反应而不是操作精度；
- 关键信息永远有「第二载体」：一个动作没演好，台词、反应或物件状态还能把它送到观众面前
  （与[可替代实现](substitutable-realization.md)同一思路，本文只筛动作写法）。

## 5. 场内空间锚点

场景动作段的前两处出现，把本场依赖的空间事实用正文声明一次：

- 出入口与相对方位：「舞台左侧是内开的侧门，右侧是通向后台的长帘」；
- 可动界面的开向/拉开方向：门的内外开、帘的左右滑、盖的掀向——写进首次交互：
  「她把朝内开的门向内拉开」；
- 故事依赖的家具与高度差：吧台、楼梯、车，各一句。

之后所有动作点名锚点（「侧门」「长帘」），不写「靠左一点」「那扇门」。「内开的侧门」这类
修饰词在复用句里带上，让下游不必回查。门的开合状态在情节里被改变后，下一次提及要如实
（「半开的侧门」）。持续性空间关系由 `[连续性]` 交接已建立状态，与 SCR-05 同规。

## 6. 失败模式（命中即重写）

- 裸位移动词：走向门口、推门进入、上了车（无朝向、无领先部位）；
- 一拍超载：一句动作段里三步以上的物理步骤；
- 「突然」「随即」「走了进去」连接本应可见的物理机构；
- 结果先于原因：门关了没人碰、人已站门外没有跨界动作、地上有血没有伤口来源；
- 两个主体占矛盾位置，或穿人穿物；
- 剧情信息压在 §4 表左列的高风险动作上且无第二载体；
- 台词与动作互抢窗口：长对白塞在移动作链中间。

## 7. 示例

**不合格（模型自由发挥区）：**

> 她说完这句话，转身走到门口，推门进入房间。

四个物理步骤挤在一拍，转身方向、接触手、先迈脚、门开向全空着——正是「背对门进入」的高发写法。

**合格（拆两拍 + 中段进入 + 锚点复用）：**

> 她把最后一字咬在唇齿间，视线越过桌面落在内开的侧门上。
>
> 侧门在她左后方两步。她转过身，右手压下内门把，门向内拉开一条缝。
>
> [转场]
>
> 门开到了墙边。她已站在门内的走廊里，胸部朝向走廊尽头的安全出口，背对房间，
> 右手还搭在门把上，门半开着。

转身、拉门、跨槛各有落点；「内开的侧门」锚点在复用；省略处用 `[转场]` 声明而不是「随后进了」。

## 8. 与下游的分工边界

| 剧本层（本文） | 分镜层 | 视频层 |
| --- | --- | --- |
| 物理步骤、朝向绑定、容量分拍、空间锚点声明 | 镜边界、拆镜、首尾帧朝向一致、跨镜因果衔接 | 秒段落位、起始帧核对、终点朝向重述 |

剧本不写景别、机位、运镜和切点；写了也不构成对下游的强制——边界事实以《分镜.md》为准。
发现某场动作链反复分不进去、或题材要求超出可生成容量时，在交稿报告里点名该场，
由创作者决定改戏、改节奏档案还是留给分镜阶段处理；不在剧本里偷偷砍动作或改结局状态。
