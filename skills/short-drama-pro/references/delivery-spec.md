# 台词交付规格：语速、停顿、语气与情绪（PAC-03 / PAC-04 / PAC-05）

PAC-01 的 2 字/秒是**常速预算基线**，不是全片统一的表演速率。同一场戏里，压怒的话说得又慢又清，
抢辩的话说得又快又碎——**剧情要求变速，交付面就要把变速写成模型能响应的话**。本文件把「按剧情定的
说话方式」拆成三根杠杆、给出情绪→档位的换算表，并规定它在各模型方言里落在哪一句。

- **PAC-03**（`craft_default`）：语速与停顿按剧情逐句取值（沉缓 1.2–1.5 / 常速 2.0 / 急切 2.5–3.2 / 崩溃 3.2–4.0 可发声字/秒），改了档就重算秒数与镜长；任何档位都不落进模型赶词线以内。
- **PAC-04**（`craft_default`）：每句台词的交付面必须给全四件（谁在说 + 怎么说 + 说什么 + 什么时候说），其中「怎么说」至少两根杠杆（速度档 / 停顿位 / 音色语气），情绪词只作定调锚。
- **PAC-05**（`reviewed_invariant`）：杠杆要能被数出来——删掉杠杆词后，句子里还应剩一个秒数或位置；只剩「自然语速」类校准词即为未交付。

项目声明与创作者明确要求优先于以上三条。机械检查 `PAC04_*` / `PAC05_*` 只出 warning，
是否成立由审查者按本文件的表判断。

## 一、三根杠杆，情绪不是杠杆

视频模型（同轨生成声音的那一类）能直接响应的只有三件事，本文件称**三根杠杆**：

| 杠杆 | 写什么 | 可用词汇示例 |
|---|---|---|
| **速度档** | 快慢，以及快慢的形状 | 一字一顿、拖长、放慢半档、连着说、抢着说完、越说越快、说完最后三字变快 |
| **停顿位** | 哪里停、停多久 | 开口前停半秒、话到嘴边又咽回去、逗号处换气、句末不立刻收声、留一拍才答 |
| **音色与语气** | 音量、气息、咬字、尾音 | 压低到只有对方听见、咬着牙说、尾音发颤、鼻音重、声音发紧、气声、笑到一半才出声 |

**情绪（愤怒、震惊、委屈）不是杠杆，是三根杠杆的组合结果。**只写「她愤怒地说」，模型
自己决定愤怒长什么样——常见结果是音量拉大、语速拉快，而这往往正是这场戏不想要的那种愤怒
（压着的怒比吼出来的怒更可怕）。所以：**情绪词可以留作定调锚，但它旁边必须至少有两根杠杆**
（`PAC04`）。哪三根全空，等于把表演交给模型掷骰。

H3 那类先点名情绪再给可见泄露的写法（[表演弧](video/performance-action-timing.md#h3-反应镜先点名再给两处可见泄露-craft_default)）
与本文件不冲突：那是**画面上的**可见泄露，这里是**声音上的**杠杆落点，两边都写才完整。

## 二、档位与秒数

档位是句级的表演取值，项目声明（`format.pacing.spoken_characters_per_second`）是场/片级的预算基线。
换算成秒时按下表取**实际档位**，不要一律套 2.0——慢档台词套 2.0 会把镜长短算一截，快档台词套 2.0
又把镜长高算一截。

| 档位 | 可发声字/秒 | 用途 | 与 PAC-01 基线的关系 |
|---|---|---|---|
| 沉缓 / 威压 / 迟疑 / 濒死 | 1.2–1.5 | 一字一顿、压场、答不上来 | 低于基线，要有角色或情绪理由（PAC-01 已允许） |
| **常速（基线）** | **2.0** | 叙述、日常对话、客气应酬 | PAC-01 默认，无声明时的预算值 |
| 急切 / 抢白 / 争吵 | 2.5–3.2 | 抢话、连珠质问、报信 | 高于基线；**必须仍是人能听到的自然快**，不是赶词 |
| 崩溃连说 / 语无伦次 | 3.2–4.0 | 惊恐慌乱、哭到说不下去又硬说 | 逼近模型赶词线，句子要短、要留尾音，且回听必查 |

三条硬边界：

1. **档位再快也不越过风险线**：H3 ≈4.1、Wan 3.0 ≈4.6 字/秒是模型**被逼出来**的赶词实测速率
   （[语速基线](pacing.md#模型实测上限不是自然语速)）。预算档位最高只到 4.0，且那一档只给
   崩溃/语无伦次这类剧情真正需要的句子；落在风险线附近的句子要拆短、回听必查逐字完整。
2. **变速不能省停顿**：越急的档越容易顺手吃掉开口前的等待与句末落点，那两秒是口型与尾音活命的地方。
3. **档位写在台词旁，不写在台词里**：逐字文本是交付物，不改字、不加语气词、不加「（停顿）」进围栏。
   杠杆句可以放在逐字围栏前（各方言的默认写法），也可以紧跟在同一句之后（「她说道：“……”，
   声音压得极低」），但不能隔到下一个段落去。

## 三、情绪→档位换算表

左边是剧本里会出现的戏，右边是可直接抄进正文的杠杆组合。**同一情绪在不同人物、不同景别下落点不同**，
表是给默认值，不是配额；有更好选择就用更好的，但别只留形容词。

| 剧情里的状态 | 速度档 | 停顿位 | 音色与语气 | 一句正文示范 |
|---|---|---|---|---|
| 压着怒气（不想第三人听见） | 一字一顿、整体放慢半档 | 开口前停半秒；句末不立刻收声 | 音量压到几乎只剩气声，咬字很重 | 他开口前停了半秒，压低到只有对面听得见，一字一顿说完，尾音没收。 |
| 震惊到答不上来 | 前两字正常，后半句断掉 | 话到嘴边咽回去，留一拍才接第二句 | 声音发紧，吸气断在半路 | 她吸气断在半路，一个字没出来，留了一拍才把后半句挤出来，声音发紧。 |
| 悲恸 / 哽咽 | 明显放慢，越说越慢 | 逗号处补一次换气，句末留一秒余白 | 鼻音重、尾音发颤 | 他越说越慢，逗号处补了一口气，尾音抖得没收住，说完之后一秒没动。 |
| 急切报信 / 抢白 | 连珠、不拆句 | 只在专名后留半拍，句间空档压到最短 | 音量大但字咬得清，不糊 | 她抢着说完，中间只在地名后停了半拍，最后三字反而更清楚。 |
| 威压 / 下最后通牒 | 一字一顿，句尾拖长半拍 | 每句之间留满一拍 | 低声、平，不带怒气 | 他一字一顿，每句之间留足一拍，声音平得听不出怒气。 |
| 试探 / 撒清点子 | 前慢后快 | 句子中间留一次犹豫的停顿 | 轻、上扬，尾音带笑 | 他先慢后快，中间顿了一下，尾音带笑地扬上去。 |
| 客气敷衍 / 官方口吻 | 匀速，不快不慢 | 每句起手都同样等半拍 | 平稳、无起伏、字与字间距均匀 | 她用匀速的客气腔说完，每句起手都等半拍，字与字间隔一样。 |
| 强装镇定 | 略快（暴露处） | 被追问后先空一拍才答 | 音量偏高、气短 | 他答得比平时快半档，被追问后空了一拍，气短地接上来。 |
| 喜极 / 不敢置信 | 先顿后快 | 开口前停满一拍（信息刚落地的处理） | 音量上冲，笑到一半才出字 | 她先停了一拍，笑到一半才把字送出来，后半句快得几乎连在一起。 |
| 崩溃边缘硬撑 | 断断续续，整体偏快但拆碎 | 每半句后停一下找气 | 哑、破音、尾音丢 | 他半句一停去找气，声音哑了，最后几个字的尾音直接丢掉。 |

多人同镜时**每人一组杠杆**，且互相要有区分（一人快一人慢、一人压音量一人放大音量），
否则模型会把两个人的声音往同一个表演上并。

## 四、每句台词交付四件

一句台词要在生成里正确落地，交付面（可复制正文）必须同时给全四件，缺一件就有一件由模型猜：

1. **谁在说**：稳定说话人 ID / 角色名 + 画内还是画外 + 音色锚点（年龄、性别、高低，或已绑的 `参考音频`）；
2. **怎么说**：本句的三根杠杆（§1），至少两根；
3. **说什么**：逐字原文，不增删、不改字、不加语气词（`VID-25`）；
4. **什么时候说**：相对动作与时间线位置——在转身之后开口、在门响后被截断、说完后手仍停在杯把上。

第 4 件最常被漏，而它决定模型会不会让口型发生在画面已经切走的地方。第 2 件是**本句**的，不是全片的：
同一个人前后两句可以完全不同档。

## 五、形容词不生成声音

同一句「她低声说」，两种写法的生成差别很大：

```text
✗ 她情绪复杂地低声说：“走吧。”
✓ 她开口前停了半秒，音量压到几乎只剩气声，最后两字拖长：“走吧。”说完没有立刻收声。
```

判据（`PAC05`）：**把杠杆词从正文里删掉，剩下的句子里还应该有一个可数的秒数或位置**。
只剩「自然语速」「正常语速」「平稳」「有感情」这类校准词时，模型拿到的是许可而不是指令，
生成结果回听往往不对——补秒数或补位置，别补形容词。回听三查：字是否逐字完整、语速是不是
人耳正常的快慢、该有的停顿与尾音在不在。

不要为了让算术成立而写「语速加快」「一口气说完」去换容量——那是把装不下的问题推给模型，
最后变成赶词或静默截断（`PAC-01`）。角色确实要说得快时，快是表演本身，写档位的**理由**
（慌张、抢话、播报腔）并仍按档位实际秒数预算。

## 六、各方言落点

三根杠杆放在**围栏外**，逐字台词放在**围栏内**，各家都吃这一条：

| 方言 | 落点 | 注意 |
|---|---|---|
| MiniMax H3 | `<d>` 外的自然语言，紧跟说话人的可见动作句：`<Subject 1> (S1), on-screen, low and slow, each word pressed out, says: <d>[Chinese] …</d>` | `<d>` 内只有语言标签与逐字台词，不放秒数、不放表演指令、不放英文说明 |
| Seedance 2.0 / 2.5 | 中文自然句写在说话动作之后、「说道」之前：`她开口前停了半秒，压低声音，一字一顿地说道：“……”` | 素材绑定每次重复（`@图片1`）；杠杆属于正文句子，不属于素材清单 |
| Wan 3.0 | 同 Seedance 的「声音轻而稳，用普通话说道」句式，把档位/停顿/音色写进这句 | 音色靠 `音频N` 参考，杠杆句仍要写；两者不互相顶替 |

`参考音频`（`VID-27`）只管**音色**，不管这一句的快慢顿；绑了参考音频不等于表演已交付，杠杆句照写。
不同轨配音（`$short-drama-produce` 的 `tts` 模态）时，本文件的速度档与停顿位就是映射到供应商
`emotion` / `speed` 参数的依据，参数值仍按样句实测校准（[语速基线](pacing.md#tts-与配音的语速校准)）。

## 七、变速不豁免预算

改档位就改秒数，镜长跟着重算：

```text
16 个可发声字，沉缓档 1.4 字/秒 ≈ 11.4 秒发声
+ 开口 0.5 + 句内一处 0.3 + 收尾 0.8 ≈ 13.0 秒 → 12 秒硬顶装不下
出路：减词 / 拆镜（声音连续、画面切换、档位不变）/ 加镜头。不靠把档位调快让算术成立。
```

急档同理：2.8 字/秒时 20 字只要 7.1 秒，多出来的窗口给动作与反应落点，不要把镜长压到 8 秒
然后塞进三条动作链。分镜「声音」行的简写要把档位写进去（「16 字 · 沉缓 1.4 ≈ 11.4 秒 + 停顿 1.6 秒
≈ 13.0 秒 → 拆镜」），这是 PAC-02 简写的自然延伸，仍然只写在镜头说明，不进可复制正文当秒数指令。

## 八、自检与失败模式

交稿前逐句问（`pro_check.py` 会对 MOTION/SHOT 块报 `PAC04_*` / `PAC05_*` warning）：

1. 这句台词旁（前或后同一句里）有没有至少两根杠杆（速度档 / 停顿位 / 音色语气）？
2. 情绪形容词是否被留在原地而没有落点？（`PAC04_EMOTION_WORD_ONLY`）
3. 档位是否重新换算过秒，并按 12 秒硬顶核过？（PAC-01/PAC-02/PAC-03）
4. 多人同镜时，每个人的杠杆是否区分开？
5. 只有「自然语速」类校准词、没有秒数或位置？（`PAC05_DELIVERY_NOT_CALIBRATED`）
6. 逐字文本是否被表演需要改动过字、加过语气词？（`VID-25`，硬缺陷）

失败模式：情绪词独走｜杠杆写进 `<d>` 或引号里｜为换容量提速｜急档吃掉开口与句末停顿｜
参考音频被当成表演已交付｜同镜两人共用一套杠杆｜变速后没重算镜长｜把档位写成正文里的
「请慢速生成 1.4 字/秒」这类秒数指令（属于镜头说明，不属于交付正文）。
