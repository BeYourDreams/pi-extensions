# 视频阶段（复刻 short-drama-video-prompts + VID-28 补丁）

产出 `剧集/<EP>/视频提示词.md`：每镜 `## MOTION-... · 中文名`，字段依次
「分镜、时长、生成方式、输入参考图、静态视觉锚点、起始帧、状态链、终点」，正文标题
`### 可复制提示词`，正文非空行以 `>` 组成引用块。时长必须与所属 `SHOT-...` 数字一致。

## 目录

1. 输入准备三分法
2. 状态链正文写法（VID-28 核心）
3. 秒段与时间
4. 声音与台词
5. 失败模式

## 1. 输入准备

按分镜「输入参考图」判定路径，不猜：

- 有真实 `REF-...` 图片 → **图生视频**：槽位原样携带（顺序、路径、《名称》、用途、
  控制/不得控制范围）；外观与构图可由参考帧拥有，正文不必重复。
- 明确「创作者已选择文生视频」 → 正文必须自带**静态视觉锚点**（本镜必要的人物、造型、
  地点、构图、光线事实），不得只写「保持已有外观」——执行端没有图可保持。
- 「待补参考图」= 未准备好：列出缺口镜头与缺图用途，停在成稿之前，不静默降级文生。

音色需求且目标模型收参考音频时，按上游 `参考音频` 行语法绑定；`不得控制` 至少写
台词、语气、情绪。

## 2. 状态链正文写法（VID-28 核心）

正文顺序：静态锚点（文生时）→ 起始状态 → 有序动作（触发→接触→落点）→ 次级反应 →
运镜 → 声音 → 终点。位移动作逐条绑定：

1. **位移绑朝向**：「她背对摄影机、胸部朝向画面深处的房门，两步走到门前」，不写裸「走向门口」。
2. **跨界声明领先部位**：「左脚先跨过门槛」「右手先触到门把」。
3. **界面开向与接触相容**：内开写推/向内拉开，外开写拉；开向写进动作句本身。
4. **转身占一拍**：朝向反转先转肩再迈步；分秒段时给独立秒数。
5. **终点重述朝向落位**：最后胸/背朝向谁、站在哪、手物什么状态——下一镜从这里继续。
6. **解释式**：每拍回答「身体怎么做、碰到什么、留下什么可见结果」；判断法——这条正文原样
   复制到下一镜仍成立，就说明没写出本镜内容。
7. **重述侧位**：穿越入口的镜头写明摄影机在门内还是门外（车内/车外、帘内/帘外）与取景方向，
   与主体胸/背朝向、界面开向、穿越方向互相推出；侧位取自《分镜.md》，不在本阶段改选（`VID-01`）。

起始帧朝向核对（图生视频）：写正文前读冻结关键帧，起点朝向与移动方向矛盾时，要么在本镜把
转身写成第一拍并给足秒数，要么作为分镜缺陷回报；不赌模型自行转身，本阶段不回写分镜。

### 站位、朝向与衣着的一致（CON-08）

模型只看这一条正文，不看上一镜也不读《视觉设定.md》。每镜自己重述四类会漂的事实：
**站位（相对本场景锚点）、身体胸/背朝向、衣着主色与形制（入画范围内的部分）、两手与物件状态**；
未变的用一句「仍」字带过（「藏青外套仍扣到顶上」），变的写变化加落点（外套褪下后搭在左臂弯）。
细则与按景别的筛选见 [站位、朝向与衣着的一致](identity-continuity.md)（CON-08）：
图生视频不重复起始帧已携带的外观，但**只挂 `用途：地理` 时人物外观无人归属，衣着仍得写进正文**；
文生视频的静态视觉锚点逐个写出在场者的衣着、发型、站位与朝向。
裸写左右一律指画面左右，人物自身左右必须带主体；多人镜每人一句独立描述，不用「两人」「她们」起句。

## 3. 秒段与时间

- 显式秒段加总恰等于本镜时长，不留未分配余量，也不超；本镜时长本身 ≤12 秒。
- 复杂多步链在 12 秒内讲不完：回分镜拆镜（这是上游缺陷，不在正文暗自砍动作或改时长）。
- 选择性变换（折叠/消失/替换/破碎）写四件事：触发、精确目标范围与路径、结束状态、
  preserve_set（同框不参与变换的人、物、文字表面保持什么）。

## 4. 声音与台词

- 台词逐字来自《剧本.md》且本镜只出现一次；视觉动作段按时间和说话人引用，不再抄一遍。
- 每句从原文首字到末字，先按 [语速基线](pacing.md)（**2 个可发声字/秒** + 停顿）估完整发声
  时间再排动作；说话人与听者、身体朝向、视线关系保持可读。
- **本句的档位不是恒等于 2.0**：按 [台词交付规格](delivery-spec.md)（PAC-03）取剧情要求的
  速度档（沉缓 1.2–1.5 / 常速 2.0 / 急切 2.5–3.2 / 崩溃 3.2–4.0），用档位重算秒数后再校镜长；
  哪个档位都不准落进模型赶词线以内。不为换容量而提速。
- **每句台词把三根杠杆写进正文**（[PAC-04](delivery-spec.md#四每句台词交付四件)）：谁在说（稳定
  说话人 ID + 画内/画外 + 音色锚点）、怎么说（速度档 + 停顿位 + 音色语气，三根至少中两根）、
  说什么（逐字原文）、什么时候说（在哪个动作之后开口、说完后落在哪个动作上）。只写
  「她愤怒地说」不够：情绪词是定调锚，不是模型能执行的杠杆。
- 杠杆写在逐字围栏**外**（H3 在 `<d>` 外、Seedance/Wan 在「说道」前的那句自然语言里），
  围栏内只有语言标签与原文；也不把秒数当指令写进正文（「请慢速生成 1.4 字/秒」属于镜头说明）。
- 停顿写进时间线：开口前的等待、句内换气与情绪顿、相邻两句之间的空档、说完后的落点。
  声音不同轨时这些是配音与剪辑的对齐依据；同轨生成时按方言写法交代（如 H3 在 `<d>` 外写
  说话方式与句间停顿）。不把停顿省掉换容量——删掉的是表演，不是秒数。
- 多人同镜时每人一组杠杆且互相区分（一人快一人慢、一人压音量一人放大音量），否则模型
  会把两人的声音往同一个表演上并。
- 本镜装不下完整发声 + 停顿时，回分镜请求拆镜或延长；不在正文提速、加截断标记、静默删词。
- 无对白镜写清底声或静默覆盖区间；环境声、SFX 按剧本事实；非画内配乐按方言声明，
  不需要时明确写空。
- 默认不生成非画内字幕/caption/对白文字叠加，并在正文直接声明；画内批准文字逐字写明
  字符、语言、承载面、位置，不被全局 no-text 覆盖。

## 5. 失败模式

正文与分镜起止不一致｜复制占位句（「已确认主体/动作/终点」）｜裸位移动词｜首帧朝向与
运动冲突未处理｜穿越入口未写摄影机所在一侧｜秒段加总不等于时长｜台词二次抄写｜该拆镜的长链硬塞一镜｜「保持外观」无图
可依｜变换缺 preserve_set｜只写「她愤怒地说」没有速度档/停顿位/音色杠杆｜杠杆写进 `<d>` 或
引号里｜只有「自然语速」类校准词没有秒数或位置｜「保持上一镜外观」｜终点行漏朝向与落位｜
衣着未重述或同件衣物两种颜色｜只挂地理参考却指望它带上人物外观｜穿脱没写落点。
