# 剧本阶段（复刻 short-drama-write + SCR-23 补丁）

产出唯一一份 `剧集/<EP>/剧本.md`：场景、动作、对白、画外音、声音事实、画面文字、连续性提示与转场。
不写人物视觉身份、镜头构图、提示词——那些属于下游。

## 目录

1. 格式语法
2. 生成就绪五问
3. 因果链六项与容量换算
4. 高风险动作改写

## 1. 格式语法

- 一级标题 `# EP001 集名`；场景标题 `## EP001-SC001 内 · 地点 · 时间/天气`。
- 对白 `角色（可选表演提示）：台词`；含冒号的动作叙述别被误写成对白——动作段行首避免
  「名词短语：」开头（用破折号、逗号或动词绕开）。
- 生产标签：`[VO]` 画外音、`[OS]` 内心独白、`[SFX]` 声音事实、`[画面文字]`、
  `[连续性]`、`[转场]`。`[连续性]` 只交接由前文已演动作建立、又易在下游丢失的状态；
  不能用标签宣告镜头外从未发生某事。
- 保留创作者原文语言；非规范文本只做必要规范化。

## 2. 生成就绪五问

每场交稿前逐问自检，任一不过就地重写：

1. **朝向绑定**：位移/界面动作是否写明身体胸/背朝向哪个可命名锚点、移动方向、领先手脚、
   界面开向、终点落位？裸动词（走到门口推门进入）不合格。
2. **容量预算**：一拍是否只装一条链、链是否 ≤ 两个物理步骤？超载链的三个出路：拆拍分场、
   中段进入、`[转场]` 明确省略。
3. **高频动作**：关键剧情是否依赖微表情、单指精细、厘米级位移、空中接取？改为高频动作组合，
   并留第二载体（台词/反应/物件状态也能送达同一信息）。
4. **空间锚点**：本场出入口、可动界面开向、故事依赖家具是否已在首次出现处声明？
   后续动作是否点名复用？
5. **因果可见**：每个结果是否有已写出的原因？「突然/随后/走了进去」不算原因。

## 3. 因果链六项与容量换算

复杂位移落笔前先在上下文解链（不落盘）：

```text
主体 → 起点位置与身体朝向 → 路径与移动方向 → 领先接触（哪只手/哪只脚）
→ 目标对象与物理连接 → 可见结果（含终点位置与朝向）
```

只回答影响执行的问题；朝向从上下文必然推出的就不写，会被误读才写。

计一步：朝向反转（转身）｜一次位移动（≤3 步）｜一次跨界（门槛/车门）｜一次界面开合｜一次单手取放。
**一拍 = 一条链 ≤ 两步。** 执行窗按单镜 ≤12 秒、10 秒左右最佳设计（分镜定最终镜长）；
有台词先估发声秒数，剩余窗口再数步数——「长台词 + 转身 + 走位 + 推门 + 跨槛」两头都超载。

## 4. 高风险动作改写

| 原写法（高风险） | 改写（高频动作 + 可见结果） |
| --- | --- |
| 两指夹起米粒大的芯片 | 把芯片按进卡槽，指尖压了两次才对齐 |
| 眼中闪过不易察觉的怀疑 | 视线移开半拍，把登记表翻回刚才那页 |
| 接住扫落的钢笔 | 钢笔掉地上，俯身捡起，顿了一下才递过去 |
| 一边倒车一边解安全带回头 | 车停稳后解安全带回头（拆拍或动作放台词后） |
| 厘米级幅度把证据推离镜头 | 合上文件夹，双臂压住（结果承担信息） |

精确性本身是戏（拆弹、穿针）时，让失败风险可见——手抖、滑脱、掉落——不要求执行端一次演准。

## 5. 空间锚点

场景动作段前两处，把本场依赖的空间事实声明一次：出入口与相对方位、可动界面的开向
（「房门开向内侧」）、故事依赖的家具与高度差。之后所有动作点名锚点（「内开的侧门」），
不写「靠左一点」「那扇门」。门的状态被情节改变后，下次提及如实（「半开的侧门」）。

## 6. 戏剧手艺要点

- 每场改变信息、权力、关系、情绪、物理状态或风险；无变化的场删掉或合并。
- 阻力的转向要有可追溯的事实、筹码、权限、代价或人物行动，不能靠对手停止反应。
- 对白必须在争取、回避、试探、逼迫或重新定义关系；初稿回读删掉不承担动作或冲突的句子，
  留下的每句要能转成一个动作或表情。创作者原文不删。
- 能演的不说：`[VO]` 不复述已演出的画面；内心独白尽量外化为动作加一句、对象反应或可见物件。
- 第一拍要能独立成钩子（观众开场第一帧就看到的问题或冲突）。
- 结尾完成本集预定的戏剧/情绪功能即可，不强制追加外部事件。
- 输入给目标时长时按真实表演通读压稿；先删重复验证、解释和同义收尾。

## 7. 失败模式

裸位移动词｜一拍超载（≥3 物理步骤）｜抽象词连接本应可见的机构｜结果先于原因｜
两个主体占矛盾位置｜关键信息压在高风险动作且无第二载体｜台词与动作互抢时间窗｜
用标签宣告镜头外事实｜无变化场次。

## 8. 示例（进门）

**不合格：** 她说完这句话，转身走到门口，推门进入房间。（四步压一拍，朝向/手脚/开向全空）

**合格：**

> 她把最后一字咬在唇齿间，视线越过桌面落在内开的侧门上。
>
> 侧门在她左后方两步。她转过身，右手压下内门把，门向内拉开一条缝。
>
> [转场]
>
> 门开到了墙边。她已站在门内的走廊里，胸部朝向走廊尽头的安全出口，背对房间，
> 右手还搭在门把上，门半开着。
