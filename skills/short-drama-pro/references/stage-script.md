# 剧本阶段（复刻 short-drama-write + SCR-23 补丁）

产出唯一一份 `剧集/<EP>/剧本.md`：场景、动作、对白、画外音、声音事实、画面文字、连续性提示与转场。
不写人物视觉身份、镜头构图、提示词——那些属于下游。

## 1. 格式语法

- 一级标题 `# EP001 集名`；场景标题 `## EP001-SC001 内 · 地点 · 时间/天气`。
- 对白 `角色（可选表演提示）：台词`；含冒号的动作叙述别被误写成对白——动作段行首避免
  「名词短语：」开头（用破折号、逗号或动词绕开）。
- 对白含表演提示时，提示回答快慢 / 停顿位 / 音量气息三件事中的一到两件，不只留情绪形容词
  （PAC-03/PAC-04，[台词交付规格](delivery-spec.md)）。
- 生产标签：`[VO]` 画外音、`[OS]` 内心独白、`[SFX]` 声音事实、`[画面文字]`、
  `[连续性]`、`[转场]`。`[连续性]` 只交接由前文已演动作建立、又易在下游丢失的状态；
  不能用标签宣告镜头外从未发生某事。
- 保留创作者原文语言；非规范文本只做必要规范化。

## 2. 生成就绪七问

每场交稿前逐问自检，任一不过就地重写（第 6、7 问细则见 §6–§8）：

1. **朝向绑定**：位移/界面动作是否写明身体胸/背朝向哪个可命名锚点、移动方向、领先手脚、
   界面开向、终点落位？裸动词（走到门口推门进入）不合格。
2. **容量预算**：一拍是否只装一条链、链是否 ≤ 两个物理步骤？超载链的三个出路：拆拍分场、
   中段进入、`[转场]` 明确省略。
3. **高频动作**：关键剧情是否依赖微表情、单指精细、厘米级位移、空中接取？改为高频动作组合，
   并留第二载体（台词/反应/物件状态也能送达同一信息）。
4. **空间锚点**：本场出入口、可动界面开向、故事依赖家具是否已在首次出现处声明？
   后续动作是否点名复用？
5. **因果可见**：每个结果是否有已写出的原因？「突然/随后/走了进去」不算原因。
6. **场景视觉事实**：本场主要行动空间是否在首次出现处声明了 3–5 条观众会看到、下游能复用的
   视觉事实（布局与相对方位、固定装置的材质与状态、光源与时间光线、可见磨损/污渍/新旧）？
   只写影响表演、光线、行动或连续性的事实，不做环境描写清单。
7. **道具与文字可读**：故事依赖的道具是否按「身份＋外观＋状态」落笔，观众和下游能不能只看
   剧本就认出它、认出它此刻的状态？必须读清的文字是否给了精确内容并标 `[画面文字]`？

## 3. 因果链六项与容量换算

复杂位移落笔前先在上下文解链（不落盘）：

```text
主体 → 起点位置与身体朝向 → 路径与移动方向 → 领先接触（哪只手/哪只脚）
→ 目标对象与物理连接 → 可见结果（含终点位置与朝向）
```

只回答影响执行的问题；朝向从上下文必然推出的就不写，会被误读才写。

计一步：朝向反转（转身）｜一次位移动（≤3 步）｜一次跨界（门槛/车门）｜一次界面开合｜一次单手取放。
**一拍 = 一条链 ≤ 两步。** 执行窗按单镜 ≤12 秒、10 秒左右最佳设计（分镜定最终镜长）；
有台词先按 [语速基线](pacing.md) 估发声秒数（**2 个可发声字/秒**，开口/句内/句间/收尾停顿另计），剩余窗口再数步数——「长台词 + 转身 + 走位 + 推门 + 跨槛」两头都超载。

一拍里塞不下的长台词在剧本阶段就处理：减词、拆成两句中间插对方反应，或拆拍分场。
不要写「一口气说完」「语速加快」「抢着说」之类的提速提示去换容量——那只是把装不下的问题推给
分镜和视频阶段，最后变成赶词或静默截断。角色确实要说得快时，那是表演本身（慌张、抢话、播报腔），
在括注里写明理由，不写成容量手段。

**`craft_default · PAC-01`**：写台词时按正常语速估秒数——可发声字（去标点与空白，数字/字母按实际
读法）除以 2，再加开口、句内、句间与收尾停顿（[停顿表](pacing.md#停顿要单独计时pac-02)）。
项目已声明 `format.pacing.spoken_characters_per_second` 时用声明值。

**`craft_default · PAC-03`**：2 字/秒是常速预算值，不是全片统一的表演速率。同一场里压怒的话更慢更清、
抢辩的话更快更碎，所以**每句台词的表演括注同时是下游的速率与音色指令**：`角色（提示）：台词` 里的
提示要能回答三件事——快慢（一字一顿 / 连着说 / 越说越快）、哪里停（开口前、逗号后、句末不收声）、
音量与气息（压低到只剩气声 / 咬着牙 / 尾音发颤）。只写「（愤怒）」「（激动）」不回答任何一件。
换算秒数时按本句档位取值（[档位表](delivery-spec.md#二档位与秒数)），不一律套 2.0。

剧本不写秒数、不写给模型的指令句式，也不把停顿写成台词里的「（停顿）」——逐字文本是交付物
（`VID-25`）。**一个情绪括注约束三处**：表演状态、发声方式、可见动作，三者不得互相矛盾
（[表演弧](video/performance-action-timing.md)）。括注里说得快要是表演本身（慌张、抢话、播报腔），
不能是容量手段；写「一口气说完」换不了时间，只逼出赶词。

## 4. 高风险动作改写

| 原写法（高风险） | 改写（高频动作 + 可见结果） |
| --- | --- |
| 两指夹起米粒大的芯片 | 把芯片按进卡槽，指尖压了两次才对齐 |
| 眼中闪过不易察觉的怀疑 | 视线移开半拍，把登记表翻回刚才那页 |
| 接住扫落的钢笔 | 钢笔掉地上，俯身捡起，顿了一下才递过去 |
| 一边倒车一边解安全带回头 | 车停稳后解安全带回头（拆拍或动作放台词后） |
| 厘米级幅度把证据推离镜头 | 合上文件夹，双臂压住（结果承担信息） |

精确性本身是戏（拆弹、穿针）时，让失败风险可见——手抖、滑脱、掉落——不要求执行端一次演准。

## 5. 空间锚点

场景动作段前两处，把本场依赖的空间事实声明一次：出入口与相对方位、可动界面的开向
（「房门开向内侧」）、故事依赖的家具与高度差。之后所有动作点名锚点（「内开的侧门」），
不写「靠左一点」「那扇门」。门的状态被情节改变后，下次提及如实（「半开的侧门」）。

## 6. 场景视觉事实（SCR-24A）

场景标题给出地点名，但地点名不是画面。本场动作段开头（与 §5 空间锚点声明可以合并落位），
把观众会看到、下游要复用的视觉事实声明一次：

- **布局与相对方位**：主要家具/界面之间的位置关系（「售票窗正对入口，退票口在玻璃下方」），
  给分镜留站位与轴线依据；
- **固定装置的材质与状态**：会进画面或被交互的表面（「玻璃上有两道划痕」「荧幕已经熄了」）；
- **光源与时间光线**：只写改变表演或氛围可见度的事实（「只剩售票窗口那一盏灯」）；
- **磨损、污渍、新旧**：承担叙事信息的表面事实写一次并被点名复用（「时刻牌背面有涂改过的数字」）。

规则：**首次出现处声明一次，后续动作点名复用，状态被情节改变后如实更新**（同 §5 的门）。
禁止：整段环境散文、与戏无关的陈设罗列、把资产级完整设定写进剧本（那属于 `$short-drama-assets`，见 §10 失败模式与格式文档 §8）。

## 7. 道具详细描述（SCR-24B）

道具不是装饰名词。故事依赖的道具（推动情节、传递信息、改变关系或被再次出现的）在**首次出场**
按三段写清，一段内完成，不另起标签：

1. **身份**：可识别的名称＋类别，与前后场复用同名（「黄铜钥匙」不写成「一把钥匙」再写成「金属钥匙」）；
2. **外观**：形状/大小/颜色/材质中**观众会看到且下游能画的**那几条（「票是巴掌大的硬纸船票」）；
3. **状态**：此刻的可观察状态与新变化（「湿透」「背面有两个新打的圆孔」）。

尺寸、颜色、材质只有影响表演、识别、动作或连续性才写——「米粒大的芯片」逼出高风险微动作，
改按 §4 写成结果承担信息。持物交接、损坏、消耗、移动用可见动作写出并交给 `[连续性]`（同格式文档 §3.3）。
一次性、不承担信息的名词道具不展开，避免每场让观众重学一套证据（`script-craft.md` 同口径）。

## 8. 画面文字与道具表面文字（SCR-24C）

凡是观众**必须读清**的文字，两处不能含糊：

- **载体写全**：文字长在哪个道具的哪个面上（「票正面」「白板右上角」「手机锁屏」），载体本身按 §7 已声明；
- **内容给精确文本**：写观众看到的原文，不改写、不概括、不意译（`票面日期：11月6日`，不是「票上有日期」），
  并标 `[画面文字]`（语法见格式文档 §3.3）。

只需「看得出有字/有图」而内容不重要的，用外观状态写即可（「屏幕上是一串看不清的数字」），
**不要滥用 `[画面文字]`**——该标签为可读性存在，一般道具说明不该用。文字内容跨镜/跨场被引用时，
两处逐字一致；拿不准精确文本时标为待决定交创作者，不擅自编造。

## 9. 平台内容安全（SAF-01）

平台对 `剧本.md` 做文本内容安全检测，命中即整份退回「文本未通过内容安全检测，请修改后重试」。
叙述、对白、`[画面文字]`、标签后的说明一律被扫，没有「这是剧情需要」的豁免。
冲突强度留在戏里，触发词不能留在字面：换成可拍摄的动作、物件状态与他人反应，信息照样送达。

| 类别 | 不要写的字面 | 换成 |
| --- | --- | --- |
| 伤害/自伤过程 | 手法、工具名、动作路径、血流出过程、吞药/服毒 | 结果状态与他人反应：纱布渗色、他松了手、她跪倒、旁人别过脸 |
| 血腥细节 | 血泊、血淋淋、开膛、爆头、血浆、肢体、内脏、尸体描写 | 遮挡与省略：手臂挡住视线、只留地面的鞋、门关上 |
| 违禁物 | 具体毒品名（大麻/冰毒/K粉/迷药）、枪支型号、赌博项目名（百家乐/老虎机/六合彩） | 中性载体：白色小袋、黑布袋、筹码；只写递交与收起 |
| 性与擦边 | 床戏动作、裸露、裸体、脱衣、身体部位特写 | 时间跳跃：门关上、灯灭、次日衣物与两人的距离 |
| 脏话辱骂 | 粗口、人身侮辱词 | 语气承担：短句、称呼降级、停顿、沉默施压 |
| 真实专名 | 真实人名/明星、公司、机构、品牌、商标 | 一律虚构；画面文字用占位（XX 集团、A 市） |
| 政治/宗教/民族/地域 | 任何相关专名与影射 | 删；动机降到私人层（钱、面子、亲情、旧账） |
| 未成年人受害 | 未成年角色承受暴力、性暗示、被侵害 | 承受方写成成年人；未成年人只出现在被保护位 |
| 极限词/承诺 | 最、第一、国家级、治愈、稳赚 | 剧本不需要，删 |

写法底线：

- 反派可以很脏，但写的是**他要什么、怎么施压**，不写手法说明。
- 狠劲放在关系与代价上（谁失去什么、谁在谁面前低头），比细节更狠也更安全。
- 必读文字（`[画面文字]`）尤其危险：不写真实品牌、真实号码、真实机构。
- 剧本没改干净的词，分镜和提示词会把同一处再触发一次；一次改完。

被平台退回来的处理：定位提示对应的原文段 → 按上表换成动作/反应/状态 → 保留同一场的信息与因果，
不降剧情；改完重跑 `pro_check.py`（`SAF01_HIGH_RISK_TERM` 只覆盖常见硬词，专名与擦边靠人读）。

硬词表与 `scripts/pro_check.py` 的 `SAFETY_RE` 同步维护：新增触发词改那处正则，并在 `--selftest` 里加一条断言，
别只改文档——文档拦不住字面，正则才拦。

## 10. 戏剧手艺要点

- 每场改变信息、权力、关系、情绪、物理状态或风险；无变化的场删掉或合并。
- 阻力的转向要有可追溯的事实、筹码、权限、代价或人物行动，不能靠对手停止反应。
- 对白必须在争取、回避、试探、逼迫或重新定义关系；初稿回读删掉不承担动作或冲突的句子，
  留下的每句要能转成一个动作或表情。创作者原文不删。
- 能演的不说：`[VO]` 不复述已演出的画面；内心独白尽量外化为动作加一句、对象反应或可见物件。
- 第一拍要能独立成钩子（观众开场第一帧就看到的问题或冲突）。
- 结尾完成本集预定的戏剧/情绪功能即可，不强制追加外部事件。
- 输入给目标时长时按真实表演通读压稿；先删重复验证、解释和同义收尾。

## 11. 失败模式

裸位移动词｜一拍超载（≥3 物理步骤）｜抽象词连接本应可见的机构｜结果先于原因｜
两个主体占矛盾位置｜关键信息压在高风险动作且无第二载体｜台词与动作互抢时间窗｜
用标签宣告镜头外事实｜无变化场次｜
场景只有地名没有可见事实｜道具只报名词无身份/状态、同一道具换名复用｜
必读文字只有「写了日期」没有精确内容、或 `[画面文字]` 贴了不必读清的说明。

**外观与装束（CON-08 的剧本侧）**：剧本不定设计（长什么样、穿什么归 `$short-drama-assets`），
但**外观什么时候变**只有剧本能说：换装、外套被拖开、袖子被抓裂、头发散去、伤在哪一侧——
不写下来，下游只能猜，猜出来就是跳错。变化由可见动作造成并交出 `[连续性]`（同 §7 道具状态口径），
换上的衣物从哪来、脱下的去了哪里也要可见；不得靠场景切换默默换衣服。

**合格：**

>
> 侧门在她左后方两步。她转过身，右手压下内门把，门向内拉开一条缝。

## 13. 示例（场景视觉事实 / 道具 / 表面文字）

**不合格：** 深夜，办公室。李明桌上的文件堆得很高。他看了一眼手机，屏幕上是他妈发来的消息。
（只有氛围词，没有可复用方位/光源/状态；道具无身份与外观；必读文字被意译）

**合格：**

> 百叶窗缝外只剩走廊应急灯的绿光，把办公桌面切成一条亮带。李明那张桌子靠窗，门在他右后方五步。
>
> 桌角压着一张对折的缴费通知单，红章在右下角。他把它推进亮带里。
>
> [画面文字] 缴费通知单：欠费 ¥4,820，限 10 月 23 日前结清
>
> 手机屏幕亮了一下——锁屏最上面一条通知写着「妈」。
>
> [连续性] 缴费通知单仍折着放在李明右手边第一格抽屉里。
