# 运动物理：位移动作的朝向与因果

`VID-28 · reviewed_invariant`。把「起点 → 唯一动作 → 终点」里的位移类动作写成身体能执行的句子。
本文件管动作的物理正确性，不管模型方言语法；方言仍按 `seedance-2.0.md`、`minimax-h3.md` 等命中文件写。

## 1. 何时启用

本镜唯一动作涉及下列任一类，才按本文逐条核对；原地手部动作、无位移表演不受约束：

- 进入、离开、穿过门口/门槛/帘幕/车窗/轿厢/台阶；
- 推、拉、扶、关门等与可动界面交互的位移动作；
- 追、逃、拦截、后退、绕行走位；
- 搬、抬、牵引着物体一起移动。

## 2. 先解链，再落笔

复杂位移在写正文前，先在上下文解一遍，不落盘：

```text
主体 → 起点位置与身体朝向 → 路径与移动方向 → 领先接触（哪只手/哪只脚）
→ 目标对象与物理连接 → 可见结果 → 终点位置与终点朝向
```

只回答影响执行的问题：每个行动主体从哪开始、往哪移动、什么连着什么、哪只手脚承担关键动作、
什么可见变化证明动作发生了、最后停在哪朝哪。简单的一步位移不必套全六项，朝向会被误读才写。

## 3. 可复制正文的绑定规则

1. **位移绑朝向，不写裸位移动词。**「她走向门口」不合格；写清胸/背相对画面内可命名锚点
   （门、桌子、另一人）的方向，再写移动：「她背对摄影机、胸部朝向画面深处的房门，两步走到门前」。
   左右用词沿用[交付形态](delivery-profile.md)的约定：裸写左右指画面左右，人物自身左右必须带主体。
2. **跨界动作声明领先部位。**跨门槛、上车、推门入手，写明哪只脚先迈、哪只手先接触：
   「左脚先跨过门槛」。不写，模型随机决定，下一镜接不住。
3. **界面开关方向与接触方式相容。**门朝里开就写推、朝外开就写拉或旋握把手后拉；
   门的开向、帘幕的拉开方向、盖子的开启方式属于本镜的空间事实，与动作写在同一句里，
   让提示词自身携带因果，不依赖模型猜结构。
4. **转身自己占一拍。**镜内含朝向反转时，先转肩再迈步：「上半身转离摄影机，双肩落向门的方向，
   随即起步」。转身要进秒段就给它独立秒数，不与位移共享同一拍。
5. **终点重述朝向与落位。**终点行除位置和持物外，写清最后胸部朝向谁/哪个锚点、背对什么，
   让下一镜从同一朝向继续，不靠「回到上一镜状态」这类占位句。
6. **解释式，不堆动词。**每拍回答「身体怎么做、碰到什么、留下什么可见结果」。
   「她推门进入房间」把四个物理步骤压成一句话，等于把转身方向、接触手、先迈脚、门的去向
   全部交还给模型。
7. **重述侧位，别让动态把内外翻过来。** 穿越入口的镜头，正文第一句除主体朝向，还要写明
   摄影机在门内还是门外（车内/车外、帘内/帘外）与取景方向，终点行重述；正文任何一句都不得
   与该侧位矛盾——已声明摄影机在门外，就不能再写人物面向镜头进门。侧位来自《分镜.md》已接受的
   记录，本阶段不改写、不重选（`VID-01`）；分镜根本没写侧位时，按第 4 条同样回报为分镜缺陷。

## 4. 起始帧朝向核对

图生视频默认延续起始帧的身体朝向。写正文前读冻结关键帧：

- 起点朝向与移动方向一致——照常写；
- 不一致（如首帧正脸对镜头、动作却是「走向门离开」）——两个合法出路：在本镜把转身写成
  第一拍并按第 3.4 条给足时间；或把「首帧朝向与动作方向矛盾」作为分镜缺陷报告回《分镜.md》
  owner。本阶段不回写分镜或关键帧（VID-01），也不赌模型会自行转身。

文生视频没有帧可核对，更要按第 3 条把起点朝向写进静态视觉锚点和本镜第一拍。

## 5. 失败模式（命中即改写）

- 有位移却全句无身体朝向；
- 未写摄影机所在一侧：本意背影入场，结果却从门内朝外拍、人物正面朝镜头走进来；
- 人物背对目标进门、进门时双手在身后操作、侧身滑步或倒退移动；
- 领先手与领先脚互相矛盾（右手推门却声明右脚先跨且同句要求并步）；
- 两个主体占同一位置，或穿人、穿物而过；
- 结果先于原因出现：门关了没人碰、人已在门外没有跨门槛；
- 用「突然」「随后」「走了进去」掩盖缺失的动作机构；
- 镜内瞬移：起点在桌边，终点在门口，中间没有走。

判断方法：把这段提示词交给一个看不见参考帧的人演一遍，他若必须自己发明朝向、手脚和开关方式
才能站起来走到终点，这段就没有写出本镜的物理内容（VID-08 同一判断法）。

## 6. 示例：进门

**不合格：**

> 她起身走向门口，推门进入房间。

四个物理步骤压成一句，转身方向、接触手、先迈脚、门开向全部缺失，模型最容易给出倒退走或背对门进入。

**合格（单镜，从链中段进入，秒段示意）：**

> 起始：她站在书桌与房门之间，背对房门、胸部朝向桌面，右手已搭在门把上。
> 0–1.5s 右手向下压门把，门向内侧打开，她同时转离桌面，双肩落向门口。
> 1.5–4s 她背对摄影机向画面深处的门口走两步，左脚先跨过门槛。
> 终点：她已进入房内，仍背对镜头、胸部朝向屋内窗的方向，右手垂回身侧，门半开在身后。

**合格（链超载，报告回分镜拆镜）：** 若分镜把「转身 + 走到门 + 推门 + 跨槛 + 长对白」装进同一镜，
时长容量不成立（VID-05），不在此阶段暗自砍动作或改时长，按工作流第 5 步回到分镜修订。
