# 调度物理：位移动作的因果链与拆镜

`SHT-30 · reviewed_invariant`。把「起点 → 唯一动作 → 终点」拆成身体能执行、下一镜能接住的位移链。
本文件管镜头边界怎么配合动作物理；景别、轴线和屏幕方向仍按[调度手册](blocking-playbooks.md)与
[镜头手艺](shot-craft.md)决定。

## 1. 何时启用

本镜唯一动作涉及下列任一类才按本文核对；原地动作、无位移表演不受约束：

- 进入、离开、穿过门口/门槛/帘幕/车窗/轿厢/台阶；
- 推、拉、扶、关门等与可动界面交互的位移动作；
- 追、逃、拦截、后退、绕行走位；
- 搬、抬、牵引着物体一起移动。

## 2. 因果链六项

复杂位移在落笔成「起点 → 唯一动作 → 终点」之前，先在上下文解链，不落盘：

```text
主体 → 起点位置与身体朝向 → 路径与移动方向 → 领先接触（哪只手/哪只脚）
→ 目标对象与物理连接 → 可见结果 → 终点位置与终点朝向
```

只回答影响执行的问题，简单位移不套全六项。链的答案直接决定镜长和拆点：一步迈步一秒能走完，
「转身 + 穿过房间 + 推门 + 跨槛 + 说完一句台词」在单镜 12 秒上限内装不下（SHT-31），就是镜头边界没画对。

## 3. 写进起点、唯一动作与终点

- **起点**：写清行动主体此刻胸/背朝向哪个画面内可命名锚点（门、窗、另一人），以及
  手脚与界面的初始接触状态。朝向只在工作会被误读时才写，但位移动作几乎总会误读，
  所以位移镜的起点默认带朝向。
- **唯一动作**：位移与朝向写成同一句因果，不是两个字段各写各的——「她胸部朝向画面深处的
  房门，背对摄影机走到门前，右手压下门把把门向内推开」。跨界声明领先部位（左脚先跨门槛）；
  界面开关方向与接触方式相容（朝内开是推，朝外开是拉）。裸写左右指画面左右，
  人物自身左右必须带主体（与下游约定一致）。
- **终点**：重述最后的位置 **和朝向**——进入房内、仍背对镜头、胸部朝窗。终点朝向是下一镜的
  起点约束，漏写它，下一镜就在各自猜。
- 转身是占用时间的动作，不是可省略的过渡：镜内含朝向反转时，把它列为链的第一拍并在起点
  交代反转前的朝向。

## 4. 中段进入与拆镜

一镜只装一条位移链。链超出镜长或模型动作容量（四步以上双手编排、多段精确衔接这类高负载动作）时，按可见状态边界拆镜，或让本镜**从链中段开始**：

- 把「转身 + 走位」归入上一镜的结果，或索性不拍——本镜起点直接是「手已搭在门把上」；
- 拆出的每镜仍各有唯一职责（SHT 镜要求），不是为了凑秒数切碎；
- 门口、门槛、上下车这类界面是天然的交界：拆点落在界面上，两端各自闭合。

## 5. 跨镜因果衔接

链必须跨镜时，前一镜停在**可见的未完成原因**，后一镜从**对应的物理结果**开始，
朝向、领先部位、物件状态两端一致：

- 前镜终点：门刚被推开一条缝，她右手还在门把上，身体已转向门；
- 后镜起点：同一只右手把门推到底，左脚开始跨门槛。

反例是用抽象词掩盖机构：「随后她进了房间」「突然门开了」。`[连续性]` 标签只交接已由前文动作
建立、易在下游丢失的状态，不能替镜头拍出门这个动作。

## 6. 与冻结关键帧的配合

冻结关键帧只投影起点，因此：

- 起点身体朝向与移动方向必须一致——首帧正脸对镜头、动作却是「走向门离开」的组合，要么把
  起点改在转身后，要么把转身留给上一镜，不指望图生视频模型自行把身体拧过去；
- 关键帧里门的开合状态、界面几何（门关着/半开）与链的起点接触方式一致；
- 需要首尾成对时，收尾关键帧按终点重写：位置、朝向、领先部位、门的去向都换成终点状态。

## 7. 失败模式（命中即改写）

- 位移动作全程没有身体朝向，或朝向与移动方向不相容（倒退走、侧滑、背对目标进门）；
- 一镜塞下整条多步链，或同句要求两个主体占矛盾位置；
- 跨界动作没有领先部位，下一镜换手、换脚接不住；
- 界面开向与动作相反（朝外开的门被「推开」穿门而过）；
- 结果先于原因：门关了没人碰、人已在门外没有跨槛；
- 用「突然/随后/走进」连接本应可见的物理步骤。

判断方法：把起点、动作、终点三段读给一个看不见分镜的人，他若必须自己发明朝向、手脚和开关
方式才能走完全程，这条链就没写完整。

## 8. 示例：进门拆两镜

剧本动作：`她说完这句话，转身走到门口，推门出去。`

**不合格（单镜装全链）：**

> 起点：她背对门站在桌前 → 唯一动作：她走向门口推门进入 → 终点：她出了门。

转身、走位、推门、跨槛、出门五个物理步骤压成一拍，「进入」与「出去」还互相矛盾。

**合格（在界面上拆，前镜止于未完成原因）：**

```text
## SHOT-012 …
起点：她站在书桌右侧，胸部朝向窗外，右手垂在身侧；房门在她左后方两步。
唯一动作：她说完最后一字，下颌先转向门的方向，双肩随之转过去，
          右脚起步，背对摄影机走到门前，右手搭上内门把。
终点：她背对摄影机立于门前，右手握内门把，门把压下沉了半寸，门尚未开。

## SHOT-013 …
起点：接上一镜终点——她背对摄影机立于门前，右手握门把，门把已压沉半寸。
唯一动作：右手把朝内开的门推到底，左脚先跨过门槛，她走进门外的走廊，
          走廊的逆光在她身后勾出轮廓。
终点：她已在门外走廊，胸部朝向走廊深处，背对房内摄影机，门半开在右手边。
```

两镜的朝向、持门手、门开向和跨界脚在交界处逐字对得上，正反机位由轴线决定（见调度手册）。
