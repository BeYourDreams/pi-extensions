## 语法兼容（与上游一致）

标题、字段与槽位写法保持上游口径，产物可被上游检查器与生产链直接消费：

- 标题：`# EP…`／`## EP…-SC… 内 · 地点 · 时间/天气`／`## SHOT-…`／`## MOTION-… · 中文名`；
- 关键帧与正文块：`### 冻结关键帧提示词`、`### 收尾关键帧提示词`、`### 可复制提示词`（`>` 引用块）；
- 参考槽位：`REF-<slot>（顺序：<n>）· <项目相对路径>《<中文名称>》（用途：<用途>；控制：<范围>；不得控制：<范围>）`，
  项目外挂图用同语法 `PLAN-...`；`用途` 取 `身份/造型状态/地理/构图/尺度/效果/起始帧/结束帧/风格`；
- 生产标签：`[VO] [OS] [SFX] [画面文字] [连续性] [转场]`。

## 字段交接

- 分镜从剧本接：场景 ID、动作因果段、`[连续性]` 状态、`[SFX]` / `[画面文字]` 事实。
- 视频阶段从分镜接：`时长`（原样，≤12 秒）、`起点/唯一动作/终点`（只实现不回写）、
  `输入参考图` 槽位（原样携带）、`视觉依据` 条目名。
- 冻结关键帧 → 图生视频：起始帧只管起点外观与构图；终点必须由运动正文写出。
- 生产阶段从视频提示词接：`MOTION-...` 可复制正文 + 已绑定的真实 `REF-...` 文件。

## 补丁映射（复刻来源）

| pro 规则 | 复刻来源 |
| --- | --- |
| 单镜 ≤12s／10 秒最佳，总长不设限 | SHT-31（含 `storyboard_check.py` 的 12.0 上限） |
| 位移动作朝向绑定、领先部位、界面开向、终点重述 | SCR-23 / SHT-30 / VID-28 三份 action-physics |
| 一拍 ≤ 两物理步、中段进入、未完成原因→对应结果 | 同上（剧本/分镜/视频三层共用词汇） |
| 生就维七问（新增「场景视觉事实」「道具与文字可读」，即 SCR-24A/B/C） | 原 write 阶段 SKILL「生成就绪硬约束」；SCR-24 为本项目补充 |
| 逐句语速档与发声杠杆（情绪词不单独交付） | PAC-03/PAC-04/PAC-05（`references/delivery-spec.md`），本项目补充 |
| 每镜重述站位/朝向/衣着/手持以保持人物一致 | CON-08（`references/identity-continuity.md`），承 VID-28 与 CON-01/CON-07，本项目补充 |

`pro_check.py` 是这些纪律的轻量机械版；需要结构终审时用 router 的
`creator_markdown_check.py`（仍在 `$short-drama` 技能内，口径一致）。
