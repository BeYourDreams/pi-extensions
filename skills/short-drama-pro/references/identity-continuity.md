# 站位、朝向与衣着的一致（CON-08）

**`craft_default · CON-08`**：模型不看前一镜，也不读《视觉设定.md》——**它只看这一条正文**。
上一镜里她穿藏青外套、背对门站在桌左侧，这一镜的正文没写，模型就有完全的自由换一件米色外套、
让她正面朝镜头。跨镜一致不是靠「刚才生成过」维持的，是靠**每一镜的交付面各自把该锁的事实重述一遍**
维持的。本文件规定重述什么、重述到哪一句、什么时候可以不写。

它把 VID-28（朝向绑定）与 CON-01（相连边界）落到「每镜都得自己写」这一层：VID-28 管动作怎么写，
CON-01 管两镜之间对不对，**CON-08 管单镜正文有没有把可漂移的外观与站位写进去**。

## 一、四类会漂的事实

| 类别 | 必须锁的最小事实 | 漂了的后果 |
|---|---|---|
| **站位** | 相对本场景锚点的位置（桌左侧、门口第三步、病床右手边） | 两人突然换边、道具跑到另一侧、正反打对不上 |
| **朝向** | 胸/背朝向哪个可命名锚点（胸部朝向窗、背对摄影机） | 「背影离场」生成成正面入场；轴线跳掉 |
| **衣着** | 主色 + 形制 + 一件可识别单品（藏青立领外套、袖口磨白） | 同一场戏里外套换色、换款式；观众认不出是同一个人 |
| **手持与穿戴状态** | 哪只手拿什么、外套是扣着还是搭在臂弯、伤在哪一侧 | 上一镜脱下的外套下一镜又穿在身上；左手的伤跑到右手 |

每一镜按**本镜实际入画的范围**取用这四类：手部特写不写全身服装，空镜不写人，
背影镜不写脸。锁不该锁的比漏锁更贵——它会把模型按到一张看不见的表面上
（`SHT-24`：声明的控制范围不能超出这一帧能承载的东西）。

## 二、写在哪一句

顺序固定，让下一镜和审查都能按位置找到它：

```text
起始帧 / 起点：<名字或稳定 ID> + <胸/背朝向哪个锚点> + <站在哪个锚点的哪一侧>
              + <此刻的衣着与手持状态（入画范围内）>
状态链：只写本镜真正参与变化的外观与站位；未变化的用一句「仍」字带过
终点：<最后胸/背朝向谁> + <站在哪> + <两只手与物件什么状态> + <衣着若变，变成什么>
```

三条写法纪律：

1. **重述要带锚点，不带形容词**。「仍站在桌左侧、胸部朝向窗」合格；「保持上一镜的样子」
   不合格——执行端没有上一镜（`VID-03`：没有真实参考帧时正文必须自足）。
2. **未变也要说一句「仍」**。只写变化会让模型以为没写的部分可以随便来；
   「藏青外套仍扣到顶上」一句就把整件衣服锁住，比列一遍衣柜便宜。
3. **终点朝向是下一镜的起点约束**（SHT-30 / VID-28）。终点行漏掉朝向，下一镜的起点就只能猜，
   猜错要退两镜修。

## 三、入画即锁：按景别筛

- **特写/大特写（手、眼、物件）**：锁那只手、那只眼、那个表面；**不写全身衣着**。
  服装锁写在 `造型` 条目入画时（`$short-drama-assets` 的连续性锁同口径：入画范围决定锁的粒度）。
- **近景（胸以上）**：锁发型剪影、领口与肩线的衣着、身体朝向；站位可以只写「仍在桌左侧」。
- **中景/全景**：四类全锁，尤其要写清人与场景锚点的相对位置（谁离门近、谁在窗那侧）。
- **空镜 / 无人镜**：不写人；但同场景的陈设与光态要「仍」一句，防止下一镜回人时空间被重排。

同一场景相邻几镜从不同景别拍同一个人，**每镜都按本镜景别重述一次**，不靠「上一镜已经写过」。

## 四、图生 vs 文生：谁拥有外观

| 路径 | 外观归谁 | 正文必须写什么 |
|---|---|---|
| 图生视频，`用途：起始帧` | 参考帧拥有起点构图与可见状态 | 不重复帧里已有的外观；但**朝向与移动方向冲突**要按 VID-28 处理（把转身写成第一拍给秒，或回分镜改关键帧） |
| 图生视频，另挂 `用途：身份` / `造型状态` | 身份板锁长相与体态，造型板锁服装与损污 | 正文只写本镜会变的（袖子被扯破、外套滑到肩），未变的用一句「仍」带过；两者别互相顶替（身份板不决定构图，场景板不决定长相） |
| 图生视频，只挂 `用途：地理` | 场景板锁空间，**人物外观没有归属** | 人物的衣着与手持必须写在正文里，不能指望场景板带上人 |
| **文生视频** | **全部归正文** | 静态视觉锚点里逐个写出在场者的衣着主色与形制、发型、站位与朝向；一句「保持已有外观」在这里等于什么都没写 |

`参考音频`（`VID-27`）只管音色，不携带任何外观或站位事实，别把它当成一致性凭据。

## 五、换装与伤情：显式声明才算批准

情节内的变化（换装、受伤、外套脱掉、头发散了）必须有**可见原因与落点**，并写进连续性记录：

- 剧本：`[连续性]` 标签或动作段写出变化由哪个已演动作造成；
- 分镜：起点与终点分别写变化前后的状态，变化本身由某一镜的动作完成，不许在两镜之间静默发生；
- 正文：写动作（她把外套从肩上褪下，搭在左臂弯），并写**落点**——脱下的衣服去哪了。
  没有落点的穿脱，下一镜十有八九又回到穿好的样子（`CON08` 的机械检查抓这一条）。

跨集或闪回里「本该没有」的外观变化不能被正文顺手补上：没在分镜登记的换装，正文不许写。

## 六、多人同镜与左右

- 裸写的「左/右」一律是**画面左右**；人物自身的左右必须带主体（「她的右手」「他的左肩」）。
  每镜重述时这条最容易写错，正反打会把画面左右翻转（同 `分镜阶段` 的轴线规则）。
- 多人镜给每人一句「名字/稳定 ID + 朝向 + 站位锚点 + 衣着」，**不用「两人」「她们」起句**；
  指代不清时模型会把两个人的外观合并（两人穿成同一件外套是高频结果）。
- 项目使用资产索引时，索引在该角色每次被提及处一并出现，但**不写进逐字台词围栏内**
  （[生产提示词语法](video/production-prompt-grammar.md)）。
- 两个人外观接近时（同款制服、双生子），正文里给一个可区分的锚点（身高差、袖口标记、站位侧），
  别只靠名字区分。

## 七、自检与失败模式

把这一镜的正文单独拿给看不见其他镜头的人读，问他三个问题：**这个人站在哪、胸朝着哪、穿什么**。
三问里有任一需要他自己发明答案，就是没写完。机械检查（`pro_check.py`）会报：
`CON08_LOOK_ANCHOR_MISSING`（正文有入画人物却既无衣着/发型一句、也无身份/造型参考槽位）、
`CON08_END_STANCE_MISSING`（终点行没重述朝向与落位）、
`CON08_WARDROBE_LANDING_MISSING`（写了穿脱没写落点）、
`CON08_LOOK_DRIFT`（同一件衣物在本档被写成多种颜色）。

这些都是 warning：是否真是缺陷由审查者按入画范围与参考图归属判断（特写镜不写全身服装是对的）。

失败模式：「保持上一镜外观」｜文生视频不带衣着主色｜只写站位不写朝向｜终点行漏朝向落位｜
穿脱没写落点｜同一外套两种颜色｜特写镜硬写全身服装｜多人镜共用一句指代｜裸左右没带主体｜
把身份板当构图板用｜靠 `参考音频` 或文件名主张外观一致｜换装没在分镜登记就写进正文。
